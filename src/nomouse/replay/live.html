Live run

Pick a page from the list. The server walks it with the keyboard (Tab through, Enter then Escape on each button), or, if you type a task, lets the keyboard navigator choose the keys; it records focus after every key, freezes the walker verdicts, then asks the model reviewer about each Enter and writes packets. The harness enforces key-only actions on an allowlisted origin: the walk cannot leave the page's own origin or send any request other than GET. Only the listed pages can be walked; no other address is accepted.

What a live run sends to the Meta Model API, and what is kept: Privacy.

With a task, such as "open the settings dialog and close it", the model chooses each key from Tab, Shift+Tab, Enter, Space, Escape, the arrow keys, Home and End, seeing only the screenshots; it types no text and stays on the page. Without one, the deterministic driver walks.

Observed keyboard-only test evidence. Not a conformance claim and not legal advice.
