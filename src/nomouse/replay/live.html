Live run

Pick a page from the list. The server walks it with the keyboard (Tab through, Enter then Escape on each button), records focus after every key, freezes the walker verdicts, then asks the model reviewer about each Enter and writes packets. The harness enforces key-only actions on an allowlisted origin: the walk cannot leave the page's own origin or send any request other than GET. Only the listed pages can be walked; no other address is accepted.
